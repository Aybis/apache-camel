# docs

Repository-level documentation that does not belong to a single folder.

| File | Purpose |
|---|---|
| [repository-map.md](repository-map.md) | One-line purpose of every folder, how they fit together, and how ACE concepts map onto them |
| `screenshots/` | Images of the console and the Grafana service dashboard, used by the root `README.md` |

The integration standards themselves (rules `STD-*`) are kept in the standards document, not in this folder:
https://claude.ai/code/artifact/10111d0f-d482-42ea-be2b-f0710f42f136

Screenshots go stale whenever the console or dashboards change. Retake them in the same pull request as
such a change, or remove them; an outdated screenshot misleads more than a missing one.
